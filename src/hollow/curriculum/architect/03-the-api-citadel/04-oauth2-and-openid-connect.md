# OAuth2 and OpenID Connect

> **Why this matters for you:** You use tokens daily; seniors can explain the flows, the threats and where JWTs go wrong.

## You should be able to
- Explain authorization code with PKCE, client credentials and refresh flows
- Validate JWTs correctly and know their pitfalls (revocation, alg, expiry)
- Choose between sessions and tokens for a given client

## Exam questions
- Why does a SPA need PKCE?
- How do you revoke a JWT before it expires?
- Service-to-service auth inside your platform: what would you use and why?
