# Authorisation Models

> **Why this matters for you:** Authentication is solved by libraries; authorisation is where real data leaks happen.

## You should be able to
- Compare RBAC, ABAC and relationship-based access
- Design multi-tenant isolation
- Enforce authorisation consistently across services

## Exam questions
- How do you guarantee one tenant can never read another tenant's survey data?
- RBAC starts to sprawl with hundreds of roles. What next?
- Where should authorisation checks live in a hexagonal service?
