# OWASP API Security

> **Why this matters for you:** Broken object-level authorisation tops the API list; knowing the list is table stakes for seniors.

## You should be able to
- Explain the OWASP API Top 10 with real examples
- Find BOLA, mass assignment and SSRF in code review
- Build defences into frameworks, not every handler

## Exam questions
- What is BOLA, and how do you prevent it in FastAPI?
- How does mass assignment happen with Pydantic models?
- Where could your services be open to SSRF?
