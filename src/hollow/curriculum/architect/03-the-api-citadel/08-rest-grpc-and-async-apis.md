# REST, gRPC and Async APIs

> **Why this matters for you:** You moved RPC to REST at work; seniors pick the protocol per interaction and can defend it.

## You should be able to
- Compare REST, gRPC and messaging for service communication
- Design resource-oriented REST APIs well
- Know when an API should be asynchronous (202 + polling, webhooks)

## Exam questions
- Why did you move from RPC to an API, and what did it cost?
- When is gRPC the better choice inside a platform?
- A report takes 2 minutes to generate. Design the API.
