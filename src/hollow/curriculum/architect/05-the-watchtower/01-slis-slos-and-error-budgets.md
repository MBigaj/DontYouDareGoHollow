# SLIs, SLOs and Error Budgets

> **Why this matters for you:** Seniors define reliability with numbers and use error budgets to argue for or against shipping.

## You should be able to
- Choose SLIs from the user's point of view
- Set SLOs and calculate error budgets
- Use error budgets in planning decisions

## Exam questions
- Write an SLO for your survey submission API.
- 99.9% vs 99.99%: what does each cost in practice?
- The error budget is spent. What changes for the team?
