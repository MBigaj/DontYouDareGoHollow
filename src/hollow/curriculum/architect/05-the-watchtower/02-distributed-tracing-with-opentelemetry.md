# Distributed Tracing with OpenTelemetry

> **Why this matters for you:** Without traces, a slow request across five services is guesswork.

## You should be able to
- Instrument FastAPI and RabbitMQ with OpenTelemetry
- Propagate context across HTTP and messages
- Sample sensibly and read traces

## Exam questions
- How does trace context cross a RabbitMQ message?
- Head sampling vs tail sampling?
- What can a trace show you that metrics cannot?
