# Graceful Degradation and Failover

> **Why this matters for you:** Systems that degrade instead of failing keep users and SLOs.

## You should be able to
- Design fallbacks and feature-level degradation
- Plan failover, RTO and RPO
- Test failure deliberately

## Exam questions
- The recommendations service is down. What should the page show?
- Define RTO and RPO for your main database.
- How would you run a game day for one service?
