# AWS Networking

> **Why this matters for you:** VPCs, subnets and security groups decide reachability, cost and blast radius.

## You should be able to
- Design a VPC with public and private subnets and NAT
- Use security groups, NACLs and VPC endpoints
- Reason about cross-AZ traffic and its cost

## Exam questions
- Why do private subnets need a NAT gateway, and what does it cost?
- How does an ECS task in a private subnet reach S3 without the internet?
- Security group vs NACL?
