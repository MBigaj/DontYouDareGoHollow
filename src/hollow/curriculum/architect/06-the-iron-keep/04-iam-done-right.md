# IAM Done Right

> **Why this matters for you:** Least privilege and role design stop small mistakes becoming breaches.

## You should be able to
- Design roles and policies with least privilege
- Use task roles and avoid long-lived keys
- Read and debug IAM policies

## Exam questions
- How does an ECS task get AWS credentials?
- A policy has 's3:*' on '*'. How do you narrow it safely?
- What is a permissions boundary for?
