# DNS

> **Why this matters for you:** DNS is in every request and behind many outages.

## You should be able to
- Explain resolution, caching and TTLs
- Explain DNS in Kubernetes and AWS
- Plan for DNS failure

## Exam questions
- Walk through resolving api.example.com from a pod.
- Why can a DNS change take hours to apply everywhere?
- How does the ndots setting slow Kubernetes lookups?
