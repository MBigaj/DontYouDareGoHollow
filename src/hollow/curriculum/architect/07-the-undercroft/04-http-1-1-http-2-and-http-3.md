# HTTP/1.1, HTTP/2 and HTTP/3

> **Why this matters for you:** Protocol versions change connection use, multiplexing and latency.

## You should be able to
- Compare the three versions
- Explain multiplexing and head-of-line blocking at each layer
- Know what your proxies and load balancers speak

## Exam questions
- What does HTTP/2 fix, and what problem remains?
- Why is HTTP/3 built on UDP?
- Does HTTP/2 matter between your services?
