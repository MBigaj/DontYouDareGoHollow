# Memory and the OOM Killer

> **Why this matters for you:** Containers die from memory limits in ways that look like random crashes.

## You should be able to
- Explain virtual memory, RSS and page cache
- Explain cgroup limits and the OOM killer
- Measure memory in containers correctly

## Exam questions
- Why can RSS and the container's memory usage disagree?
- What does the OOM killer pick, and why?
- Fork-based workers and memory: what is copy-on-write?
