# A Request, Hop by Hop

> **Why this matters for you:** Tying it all together: from typing a URL to your FastAPI handler, and back.

## You should be able to
- Explain every hop: DNS, TCP, TLS, load balancer, ingress, service, pod, ASGI, handler
- Say where latency and failure can come from at each hop
- Pick the tool to observe each hop

## Exam questions
- Walk through a request to your API, hop by hop.
- Which hops add the most latency, typically?
- Where would you look first for intermittent 502s?
