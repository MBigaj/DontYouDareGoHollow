# Time, Clocks and Ordering

> **Why this matters for you:** Ordering events across machines without a shared clock is a core senior concept.

## You should be able to
- Explain clock skew, NTP limits and monotonic clocks
- Explain Lamport and vector clocks
- Know when wall-clock ordering is unsafe

## Exam questions
- Why should you never order distributed events by wall-clock time?
- What does a Lamport clock guarantee, and what does it not?
- How would you detect concurrent updates to the same record?
