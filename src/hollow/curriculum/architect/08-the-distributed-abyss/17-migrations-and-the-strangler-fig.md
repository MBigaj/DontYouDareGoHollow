# Migrations and the Strangler Fig

> **Why this matters for you:** You have migrated RPC to API and Lambda to ECS; seniors plan migrations as architecture.

## You should be able to
- Apply the strangler fig pattern
- Run parallel and shadow traffic, and cut over safely
- Plan rollback and decommissioning

## Exam questions
- How did you sequence the RPC to API migration, and what would you change?
- What is shadow traffic, and when is it worth it?
- How do you know the old system can be switched off?
